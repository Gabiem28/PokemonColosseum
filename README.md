# PokemonColosseum
A command-line Pokemon battle game implemented for CAP4630 (Introduction to AI). This project simulates Pokemon battles using Python. 

- This program requires the following CSV files to work:
    - pokemon-data.csv
    - moves-data.csv

- To run the program:
1. Extract the ZIP file and go to extracted folder
2. In terminal, run the program using:
    python src/PokemonColosseum.py
3. Follow the on screen instructions to play the game

*This program does not require any external libraries.*
